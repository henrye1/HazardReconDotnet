What the checks mean

Check 1 — every default (Bucket 0) should appear in the write-off file or the IFRS9 file; those in neither are untraced.

Check 2 — the reverse: scored accounts written off but never flagged as a default, with the ones written off inside the scoring window flagged as the priority exceptions.
